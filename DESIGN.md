# ShopBoard design

This file explains how ShopBoard looks and why. Every value here is a token in
[`src/style.css`](src/style.css); the CSS never uses a raw color or size outside the
token block.

## 1. Reference

The starting point is the **Bento grid** style used on many product launch pages:
the page is built from rounded tiles of different tones, with a bold grotesque
typeface and one strong accent color.

What I took from it:

- Large rounded tiles (radius 28px) with no borders
- A light grey page, white tiles, and some tiles in a soft accent tint
- A display font for headings (Bricolage Grotesque) and a calm font for text (Inter)
- One accent (blue) for every action, and a warm second color (coral) only for decoration
- A soft blue and coral gradient "mesh" behind the page

## 2. What I changed and improved

The first version of the theme was generated by a tool and pasted on top of my old
styles. It worked, but it was not code I could stand behind, so I rewrote it:

- **One token system.** There were two sets of variables (`--ink` and `--rb-fg` for the
  same color). Now there is one: `--color-*`, `--space-*`, `--text-*`, `--radius-*`.
- **No `!important` and no ID selectors** for styling. Components have their own
  classes: `.button`, `.button-secondary`, `.input`, `.nav-link`, `.dialog`,
  `.status-box`, `.section-title`.
- **Layout bugs fixed.** The filter sidebar was placed with `grid-row: 2 / span 30`,
  which made 30 empty grid rows and a large gap under the products. It now uses
  named grid areas. The hero button no longer stretches to full width.
- **Every tile is visible.** Some cards used the same color as the products band
  behind them, so they had no edge. Cards are now white, and every fifth one (starting
  with the third) uses the accent tint.
- **Dark mode works everywhere.** The sticky header had a hard-coded light color. It
  now mixes `--color-bg`, so it follows the theme.
- **Contrast.** Grey text on the tinted cards was 4.2:1, under the WCAG AA minimum of
  4.5:1. `--color-muted` is now a little darker. The reference's green (`#16a34a`) is only
  2.9:1 with white text, so success toasts use a darker green (`#15803d`) instead of
  the accent blue, which also keeps blue for actions only.
- **Fewer downloads.** Two fonts in one request, only the weights the page uses. The
  monospace font was loaded but never used, so it is gone.

- Only `--color-accent` marks something you can click to act. The coral never does.
- The dark theme follows the system setting (`prefers-color-scheme`).

## 4. Typography

| Role           | Font                | Weights       |
| -------------- | ------------------- | ------------- |
| Headings, logo | Bricolage Grotesque | 700           |
| Text and UI    | Inter               | 400, 600, 700 |

Scale: 12 / 14 / 16 / 18 / 20 px, section titles 24–32px, hero title 38–70px
(the last two grow with the screen using `clamp()`). Text line height is 1.6.
Inputs use 16px so iPhones don't zoom in when you tap them.

## 5. Spacing and shape

- Spacing follows an 8-point scale: 4, 8, 12, 16, 24, 40 px. Bigger gaps separate
  groups, smaller gaps keep related things together.
- Page gutter: 16px on phones up to 40px on desktop. Content width: 1200px.
- Radius: 10px (small), 18px (buttons, inputs, cart lines), 28px (tiles and dialogs).
- Every button and input is at least 44 × 44px, so it is easy to tap.

## 6. Components

- **Primary button** (`.button`): accent background, weight 600, radius 18px.
  Slightly darker on hover, slightly smaller while pressed.
- **Secondary button** (`.button-secondary`): surface background with a 1px
  outline in the text color. Used for cart actions, "Clear cart", "Try again" and the ×
  buttons.
- **Input** (`.input`): surface background, border, radius 18px. On focus: accent
  border and a soft accent ring.
- **Product card** (`.card`): tile with a dotted placeholder (the API has no
  photos), name, category in small caps, price, and the button pinned to the bottom so
  buttons line up across a row. Lifts a little on hover.
- **Status box** (`.status-box`): dashed box for loading, empty and error messages.
- **Dialogs** (`.dialog`): the cart opens as a drawer from the right; sign-up opens
  in the center. Both blur the page behind them.
- **Toasts**: bottom of the screen on phones, bottom right on bigger screens.

## 7. Layout and breakpoints

| Width    | Layout                                                                  |
| -------- | ----------------------------------------------------------------------- |
| < 768px  | One column. Filters stacked above the products.                         |
| ≥ 768px  | Filters in one row. Product grid fills as many columns as fit (≥210px). |
| ≥ 900px  | Hero splits into text on the left and a gradient tile on the right.     |
| ≥ 1024px | Filters move into a sticky sidebar (260px) next to the products.        |

## 8. Accessibility

Contrast, measured with the WCAG formula (AA needs 4.5:1 for normal text):

| Pair                            | Light           | Dark    |
| ------------------------------- | --------------- | ------- |
| Text on background              | 16.56:1         | 16.00:1 |
| Text on surface                 | 18.91:1         | 14.77:1 |
| Muted text on surface           | 6.62:1          | 6.42:1  |
| Muted text on tinted card       | 4.81:1          | 5.67:1  |
| Button text on accent           | 5.12:1          | 5.11:1  |
| Link on background              | 5.19:1          | 6.78:1  |
| White on success / danger toast | 5.02:1 / 4.83:1 | same    |
| Badge number on coral           | 7.37:1          | 7.37:1  |

Also:

- Visible focus outline (3px) on everything you can reach with the keyboard
- All animations turn off when the system asks for reduced motion
- One `h1`, every input has a `<label>`, and status messages use `role="status"`
